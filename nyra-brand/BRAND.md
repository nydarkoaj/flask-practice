# Nyra Technologies — Brand Guide

## Name
**NYRA** = **N**.**Y**. + **R**egan **A**zenab. Short, easy to say, works as a domain/handle, and reads as one word internationally.

- Wordmark: lowercase `nyra.` with a gold full stop.
- Legal/full name: **Nyra Technologies**.
- Tagline: *Software, data and AI, built in Ghana for the world.*
- Sign-off line: *Let's build what's next.*

Alternatives considered: **Azenyr** (Azenab + NY), **NyRegan Labs**, **Nyreza Tech**.
Check availability of the name/domain and with the Registrar-General before registering.

## Logo mark
`logo.svg` — an N whose right stroke forks into a Y; the gold node at the fork stands for data and connection.
Keep clear space equal to the height of the gold node on every side. Minimum size 24px.

## Colours
| Name | Hex | Use |
|---|---|---|
| Midnight Indigo | `#18184A` | Primary background, headers, trust |
| Adinkra Gold | `#F0A818` | Accent, buttons, highlights (use sparingly) |
| Lagoon Teal | `#0E8A82` | Data, charts, secondary labels |
| Harmattan Mist | `#EEF1F8` | Light backgrounds, text on indigo |
| Night Ink | `#0B0C24` | Dark mode background, footer |

Gold text on light backgrounds should use the darker `#8A5A00` for legibility.

## Type (Google Fonts, free)
- Display: **Bricolage Grotesque** 700/800
- Body: **Instrument Sans** 400/500/600
- Labels & data: **IBM Plex Mono** 500, uppercase, letter-spaced

## Voice
Plain, confident, specific. Lead with outcomes (“websites that rank, data you can trust”), not jargon.

## Files
- `index.html` — company website (open directly, or run the Flask app and visit `/nyra/`)
- `video/nyra-promo.mp4` — 21-second promo (1280×720). Re-render with `node video/render.js` after editing `video/promo.html`.
- `video/still-*.png` — stills for social posts / thumbnails
